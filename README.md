# MapAnalyzer — Công cụ phân tích Nơi ở & Quán ăn từ Google Maps

Ứng dụng web cho phép chọn một điểm trung tâm trên bản đồ (ví dụ: **Hồ Xuân Hương, Đà Lạt**), chọn bán kính (km) và thu thập thông tin các địa điểm **Nơi ở** và **Quán ăn** từ Google Maps.

## Tính năng chính
- **Bản đồ tương tác**: Nhấp trực tiếp lên bản đồ để đặt tâm, hoặc tìm kiếm tên địa điểm/khu vực, kèm vòng tròn bán kính trực quan.
- **Hai nhóm địa điểm**: Quét **Nơi ở** (khách sạn, homestay, resort), **Quán ăn** (nhà hàng, quán ăn, cafe) hoặc **Tất cả**.
- **Thông tin chi tiết*: Hình ảnh địa điểm, số sao đánh giá, tổng lượt review, khoảng cách từ tâm, địa chỉ và liên kết mở nhanh Google Maps.
- **Lọc & Sắp xếp**: Sắp xếp theo số sao cao/thấp nhất, nhiều/ít review nhất, gần tâm nhất; lọc theo số sao tối thiểu, số lượt review tối thiểu và từ khóa.

## Cách chạy
```bash
npm install
npm run dev
```
Sau đó mở trình duyệt tại `http://localhost:5173`.
